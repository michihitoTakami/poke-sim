# みずびたしの状態復元と特殊バトン・変化技対策

PR44後の直近50戦（2026-10-20 00:11〜03:14）は28勝22敗、38対戦相手。
実際にアシレーヌが出た6戦は1勝5敗。アーマーガア＋ハラバリーが両方出た2戦は2敗だった。
出現条件が重なる小標本で、見せ合いにいただけの相手を倒された原因として数えない。
操作主体が不明な記録の提案／実行の違いは、手動操作の可能性を保持する。

## 確認した不具合

`20261020-010902-2701095776.json`の8ターン目では、ラウドボーンが既にみずびたしを受けていた。
poke-envは水タイプを持っていたが、探索へ送る状態にタイプがなく、シミュレータでは炎・ゴーストへ戻った。
電気の弱点と炎技の一致補正を取り違えるため、技選択より先に直すべき復元不具合だった。

- `observed-state-v4`は公開されたタイプ変化を双方のアクティブ個体に渡す。
  Transform・フォルムの復元後に適用し、その後の交代・メガシンカのリセットはエンジンへ任せる。
- 公開観測と継続方策のダメージ見積もりでも、防御相性と攻撃側の一致補正に現在のタイプを使う。
  poke-envがフォルム変更後も残す一時タイプは追跡層で消す。
- 身代わりでToxic／Soak／Yawnを防ぐ、サーフゴーでToxic／Soakを無効化することを
  固定エンジンで確認した。あくびを受けてからの身代わりを治療として扱わない。

## 実戦へ反映する判断と学習用のパターン

`public-relay-goals-v2`は、公開された変化技に対し、先手・HP・身代わりを壊す打点を確認して
身代わりを選ぶ。状態技を受ける前のサーフゴーへの交代も候補にし、有用な能力変化がある場合は
バトンで残す。積みへの加点は追加せず、ルートでは既存の効用差0.03以内の採用と反撃確認を維持する。

特殊バトンに「既に加速を受けた、先手のポケモン」という制限があり、通常速度のブラッキーからの
瞑想バトンを扱えなかった。これを外し、後手の回復・積みでは強化前に被弾する順番まで含めて
生存を確認する。受け手のHP・設置技・回復量・２回被弾・速度の条件は保持する。
相手の特攻上昇に対するバークアウトも、反射・負けん気系特性・身代わりを確認して候補にする。

選出は`preview-evidence-v6`。従来の妨害・物理積みに加え、特殊積みとSoak／Toxicを含む
完全な型仮説をストレス比較へ加える。見せ合いと事前分布だけから引き、後で見えた型を入力しない。
`public-counterplay-v2`は毒無効へのSoak→Toxicと、守る・バトン等への特殊積みを実行する。
これは選出の模擬戦と`learn.branches`の終局比較の相手として使われる。方策版も分岐の記録に残す。

相手の型集計では、イリュージョンの`replace`でその登場中の技・持ち物・特性を正しい種族へ戻す。
同じ６体との15分以内の再戦も、ラダーの対戦IDが異なれば別試合として残す。
`replayed frames`のような取得元の名称を対戦IDとして扱わない。
03:14までの固定データを再集計すると807試合・実際に出た206種。
これは相手が公開した型の更新であり、本人の手動操作を正解手として模倣学習する処理ではない。

## 検証結果と限界

- 全590テスト、変更したPythonのRuff、Node構文、diff検査が成功。
  現在タイプ、電気相性と一致補正、通常交代・メガでの解除、予防の成功、既存あくび、
  加速なしの特防バトン、型集計の回帰検査を含む。
- 保存した6局面で同じ4型仮説・256追加試行を比較。選ぶ手は6件とも同じだった。
  みずびたし局面の選択手の効用は0.706→0.063へ下がった。これは勝率ではない。
  既に不利になった局面を救えたという結果ではない。
- 4見せ合い、36〜40候補、各7世界・3相手方策の模擬戦を比較した。
  妨害、特殊積み、Soak／Toxicのストレス世界が生成され、失敗は0。
  1見せ合いで先頭候補が変更された。履歴の寄与も含めるよう比較スクリプトを修正した。
- 同じ16型仮説・2乱数・4種類の固定相手で継続方策を比較した128試合ずつは、双方64勝64敗。
  バトン実行回数は125→131。回数を報酬には使っていない。
  検討済み局面を使う開発診断であり、対人勝率の改善や独立した128人との対戦を意味しない。
