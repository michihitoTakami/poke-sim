## 公開構築を型と6体の仮説として使う

指定された[GameWithの上位構築一覧](https://gamewith.jp/pokemon-champions/560474)が使う公開JSONと、
同じサイトのポケモン・技・持ち物・特性マスターを保存した。
M-6シングル296掲載のうち、欠損・名前/フォルムが未解決の69件を除外し、同一6体型5件を重複排除。
残る222構築は6体すべてが揃い、現在のShowdownルールのvalidatorを通過した。
数値IDはサイト固有なので全国図鑑番号と混同せず、マスターの名前・図鑑番号・種族値・フォルムから照合する。
未記載の技・性格・配分を埋めて「掲載された型」と称する処理は加えていない。

掲載元の記事例として、[最終2位のカバルカミミ構築](https://eff4dckeqm1cwsf.hatenablog.com/entry/2026/10/10/081058)と
[最終3位のカバ武者構築](https://meltdowner.hatenablog.com/entry/2026/10/08/115914)も確認した。
元の構築における採用理由や組み合わせは、1体の使用率だけで表し切れない。
記事順や掲載順を相手の選出順とみなしたり、文章から確認していない先発・3体を正解ラベルにしたりはしない。

実行時はネット接続せず、検証済みの`data/processed/top_teams.json`を読み込む。

- 見せ合いと4体以上一致する公開構築を検索する。6体一致は強い候補になるが、実際の相手だとは断定しない。
- 技4つ・性格・配分・特性・持ち物は、掲載された型を一組として抽選する。
- 同じ仮説世界の複数体は、可能なら同じ公開構築から取る。見せ合いにない種族は追加しない。
- 公開済みの技・持ち物・特性と矛盾する掲載型を除外する。消費後の持ち物とメガ後の特性は元の型と区別する。
- ダメージ・行動順の観測尤度を使う。掲載型がすべて信頼できる行動順に矛盾したら、その構築仮説を使わない。
- 類似構築がない場合も種族単位の完全な掲載型を候補にでき、汎用priorも併用する。
- 選出の静的相性・3対3比較、実戦中のbelief・探索が同じcatalogを使う。
  相手の3体の確率は従来の公開履歴から推定し、記事の先頭3体で決めない。

catalogのhashを記録・較正条件・選出cacheへ加え、catalog変更を対戦間に検知する。
構築探索の版は`preview-continuations-v3`。既存の固定参照方策の重み・特徴量は変更しない。

次に初公開される技が、判断直前の観測から生成した型の4技に含まれる割合を比較した。
これは採用技の部分観測の診断で、実行する技の較正済み確率や、真の配分の的中率ではない。
各試合を同じ重みで平均し、各公開イベントで192候補を抽選した。

## 時間延長は終局確認へ使う

開発データから固定した8局面で、同じ4仮説に対し4ワーカーを用いて比較した。
単純な延長では、終局比較が悪い積み技・交代へ変わる局面があった。

| 設定 | 選択手を固定した終局比較での勝ち／192試行 |
| --- | ---: |
| 8.5秒・8ターン | 143 |
| 15秒・8ターン | 118 |
| 15秒・12ターン | 118 |

この比較は固定参照方策による開発診断であり、探索の真の優劣を証明しない。
少なくとも、今回のデータから単純に深さを増やす判断はしなかった。

新しい通常設定は**1手の上限15秒、通常探索8.5秒・8ターンを維持し、残りで終局比較**とした。
判断前のbeliefと仮説生成も同じ上限に含める。Showdownが通知した残り時間が少なければ短縮する。

終局比較は、同じ型仮説・2乱数・3種類の公開情報方策で、残る合法候補を最大120ターンまで比べる。
終局した全候補の比較が揃い、勝敗値が0.1以上改善し、**どの仮説×相手方策でも平均が悪化しない**場合だけ選択を変更する。
途中のHPや積み回数へ加点しない。終局に達しない、失敗、時間切れ、不足した比較があれば通常探索の手を維持する。
即勝ちの確認は最優先であり、混合戦略やnear抽選の意味も変えない。
相手も自分も公開観測と自分のrequestだけで次の手を選び、サンプルの隠れた値で方策を選び直さない。

この新しい終局比較では、相手も修正済みの技・天候評価を使う。
学習用の従来設定を維持しつつ、オンライン確認では軌跡の大量出力を省いてメモリと通信量を減らした。

同じ8局面の新しい比較内では、従来手128勝／192試行から確認後143勝／192試行となった。
6局面を維持し、2局面を変更。確認部分は0.54〜1.77秒。
上の単純延長の表とは相手方策の版が異なるため、表を跨いだ勝数の差は比較しない。
これらは8つの開発局面の仮説対戦であり、192戦の独立した対人評価とは呼ばない。
実際のAdvisor経路でも約10.8秒で合法手を返し、終局確認完了・品質エラー0を確認した。
