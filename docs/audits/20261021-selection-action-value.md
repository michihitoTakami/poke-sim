# 2026-10-21 選出・判断の分離評価と終局結果による再学習

## 対象と実行結果

①接続復旧、③選出と対戦判断の分離、④候補手の終局結果に基づく学習を実施した。
最高レートを記録した版との比較は行わない。本人の手動操作が混じるため、記録済みの
AI提案を基準とし、実行された手や勝った試合の全行動を教師にはしない。

PR #51でログイン・検索受付・対戦中の接続状態を分けて監視するようにした。
公式サーバーから検索受付を確認し、受付済みの検索は接続が生きている間維持する。
接続回復と新しい対戦の成立は別で、14:34 JST時点では新しい試合は保存されていない。

PR #50の43試合から、同じ相手・見せ合い構築の連結をまとめた24グループを分析した。
ボーマンダはいじっぱりH5/A31/S30を維持。1グループにつき1局面を比較する。
公開型仮説4通り・乱数2通り・相手方策4通りを用い、シミュレーションの失敗は0件だった。

初回は選出探索15,776試行、固定評価3,072試行、実戦局面の候補手比較4,704試行を実施。
優位度学習版では探索と局面の終局ラベルを再利用し、固定参照側1,536試行の完全再現を
確認して、新モデル側1,536試行を実行した。これらは実戦の対人試合数ではない。

## 選出を変えるだけでは改善しなかった

探索側で選んだ代替選出を、別の評価用仮説で当時のAI提案と比較した。
参照判断を固定した平均差は **−3.78ポイント**、90%区間は **−12.63〜+3.91ポイント**。
この方法で選出を置き換える根拠は得られず、本番の選出器は変更しない。

例えば`20261021-064312-…`では、元のブラッキー・サーフゴー・ボーマンダが28/32勝、
探索で選んだフラエッテ・ラウドボーン・ブラッキーが5/32勝だった。
少数の型仮説に合う選出を選んでも、別の仮説へ汎化するとは限らない。
今後は世界数を増やし、相手選出の分布、複数先発、バトンからの継続計画を含めて検証する。

## 終局結果から学ぶ方法を実装・実行した

既存の凍結済み分岐37,408試行、90グループ179局面を用いた。
学習50グループ100局面、開発20グループ40局面、歴史的な校正20グループ39局面に分離。
各候補の終局結果を学ぶ版と、局面共通の勝ちやすさを差し引いた優位度を学ぶ版を
それぞれ3モデル学習した。過去に分析した校正データなので、新規の未見テストとは扱わない。

| 比較 | 終局勝率を学ぶ版 | 優位度を学ぶ版 |
|---|---:|---:|
| 校正データ・同一局面の平均改善 | +0.55pt | +1.09pt |
| 校正データ・90%区間 | 0〜+1.64pt | −0.08〜+2.42pt |
| 24グループ・元選出で全体を進めた平均改善 | +0.52pt | +3.13pt |
| 同上90%区間 | 0〜+1.56pt | +1.17〜+5.21pt |
| 保存した実戦局面でAI提案に対する平均改善 | 0pt | −0.39pt |

優位度版はスクリプト参照方策を全体で改善したが、保存された実戦局面では改善しなかった。
`20261021-065554-2701871519.json`の8ターン目では、AI提案のブラッキー交代が
28/32勝に対し、新モデルのシャドーボールは25/32勝だった。
「弱い参照方策を改善できた」と「本番AIより良い手を選べる」は別に確認する必要がある。

今回の24局面で、仮説・相手方策をまたいでも頑健に上回る代替手は検出されなかった。
これは実戦判断が正しいという証明ではない。少数局面、型仮説、スクリプト継続の
範囲に依存し、本番の探索や人間の長期計画を十分再現できない可能性がある。
